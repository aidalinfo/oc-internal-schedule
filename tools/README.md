# Internal Schedule Tools

This directory documents the tools exposed by the `oc-internal-schedule` OpenCode plugin.

Available tools:

- `schedule_self_message`
- `list_scheduled_self_messages`
- `cancel_scheduled_self_message`

These are plugin-provided tools. They are not loaded from this `tools/` directory directly.

Use this directory as reference material for humans and for the companion skill in `skill/`.
